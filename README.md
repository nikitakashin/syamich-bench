# Сямыч Бенч

[Открыть сайт](https://nikitakashin.github.io/syamich-bench/)

Рейтинг ИИ-моделей канала AI Native Сямыч. На главной можно сортировать модели по итогу, качеству и стоимости всех ответов. Повторное нажатие меняет направление, а нажатие на название модели открывает оценки за четыре задания.

Сайт состоит из статических HTML, CSS и JavaScript. Откройте `index.html` в браузере. GitHub Pages публикует файлы из корня ветки `gh-pages`.

## Обновление после выпуска

Из этого репозитория, расположенного в папке `life`, выполните:

```sh
python3 -B scripts/update_results.py
git diff -- index.html data/results.json
```

Скрипт читает готовые измерения и авторские оценки из `../youtube/Ресерч/model-duel` и отдельные дуэли из `../шоу/сямыч-бенч-дуэль`. Пути можно передать через `--bench` и `--duels`. Обновляются таблица в HTML и общедоступный снимок `data/results.json`. После проверки зафиксируйте снимок и обновите обе ветки одной командой.

```sh
git add index.html data/results.json
git commit -m "Обновить результаты бенчмарка"
git push --atomic origin main main:gh-pages
```

Основная серия имеет приоритет, если модель встречается в нескольких наборах. Расчёт выполняет та же функция `compute()`, что и в терминальном бенчмарке. В общей таблице эталон эффективности для всех моделей — Claude Opus 5.5. Для отдельной дуэли сохраняется и исходный балл относительно её собственного эталона.

Незавершённые прогоны идут после зачётных при любом порядке сортировки. Предварительные баллы видны в деталях. Столбец цены содержит сумму зарегистрированных цен за ответы данной модели, включая оценку по тарифам API для запусков по подписке.

Пиксельные портреты в шапке — работы Opus, Astra и Fable из задания «Портрет».
